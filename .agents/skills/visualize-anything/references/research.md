# Visualizing a public topic

For a current-state request, search for recent primary sources and compare publication dates with measurement periods. Use comparable series for comparisons and report units, coverage, observation date, source link, and any exclusions near each view. Keep source-provided categories when definitions differ. Treat unreported values as missing. Separate forecasts from historical observations.

Example request: “我想看一下全球 AI 发展现状。”

- Scope the overview around questions the data can answer, such as where model development is concentrated, where investment is flowing, and how adoption varies.
- Use comparable country or region data for ranked comparisons. Use a map only if spatial patterns add value, and distinguish no coverage from a true zero.
- Show time trends when historical observations share a definition. Display country-specific adoption surveys separately if their populations or questions differ.
- Give each panel its own measurement period and source. Avoid reducing unrelated dimensions to an overall score without a defensible methodology.
